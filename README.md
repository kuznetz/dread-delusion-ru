# translate-tools — конвейер перевода Dread Delusion

Набор из трёх шагов для переноса перевода на новую версию игры. Перевод и шрифты
хранятся отдельно от файлов игры, поэтому обновление не требует заново разбирать
бинарники: распаковали — применили перевод — собрали готовые файлы.

Комплект автономный: всё нужное лежит внутри `translate-tools`, внешних зависимостей
кроме Python-пакетов нет.

Требования: Python 3 и пакеты `UnityPy`, `fonttools` (`python -m pip install UnityPy fonttools`).

## Быстрый старт (новая версия игры)

```powershell
cd translate-tools
python 01-extract/extract.py --game "D:\Games\Dread Delusion"
python 02-apply/apply.py
python 03-generate/generate.py --game "D:\Games\Dread Delusion"
```

Папку `out/Dread Delusion_Data` после сборки копируют в корень игры
(рядом с `Dread Delusion.exe`), заменив `resources.assets` и `StreamingAssets/MenuText/menuText_en.json`.
Оригинальные файлы игры стоит предварительно сохранить.

## Структура

- `data/` — всё, что нужно для перевода и не зависит от версии игры:
  - `settings.json` — настройки конвейера;
  - `versions.json` — реестр версий игры: SHA-256 (и MD5/размер) чистого `resources.assets`;
  - `translations/<таблица>.tsv` — переводы по таблицам;
  - `dictionary.tsv` — общий словарь «английский текст → перевод»;
  - `fonts/*.ttf` — шрифты с кириллицей.
- `01-extract/extract.py` — распаковка ресурсов игры:
  - берёт чистый (английский) `resources.assets` — сначала `.bak`, затем `.orig`, затем сам файл;
  - выгружает все pipe-таблицы в `work/text/<таблица>.txt` (UTF-8, как есть);
  - выгружает TrueType-данные шрифтов в `work/fonts/` (для справки);
  - пишет `work/info.txt`: таблицы, колонки, число строк, шрифты и их кириллическое покрытие;
  - опознаёт версию игры по SHA-256 чистого `resources.assets` (реестр — `data/versions.json`),
    печатает версию и сохраняет её в `work/version.json`;
  - `--import-existing <файл>` — вытащить готовый перевод из уже переведённого `resources.assets`
    в `data/translations/*.tsv`;
  - `--import-dictionary <файлы>` — дополнить `data/dictionary.tsv` парами из файлов вида
    `English=Русский`.
- `02-apply/apply.py` — применение перевода:
  - читает `work/text/*.txt`, `data/translations`, `data/dictionary.tsv`;
  - пишет переведённые таблицы в `work/ru/`;
  - `work/apply_report.txt` — что и сколько заменено, сколько ключей перевода осталось без строки;
  - `work/untranslated.txt` — строки без перевода в формате `таблица|ключ|текст`;
  - проверяет, что шрифты из `data/fonts` покрывают все кириллические символы перевода
    (`--strict` — завершаться с ошибкой, если нет).
- `03-generate/generate.py` — сборка готовых файлов:
  - подставляет переведённые таблицы в `TextAsset`;
  - вшивает шрифты из `data/fonts` в `Font`-ассеты (`m_FontData`);
  - TMP-шрифт переводит в динамический режим: атлас увеличивается до 1024x1024
    (старые пиксели остаются в левом верхнем углу), под ним появляется свободная полоса
    `(0, 512, 1024, 512)`, поля размера атласа меняются на 1024x1024;
  - собирает `menuText_en.json` из переведённой таблицы `generalData_AllLanguages`;
  - результат — `out/Dread Delusion_Data/` (`resources.assets`, `StreamingAssets/MenuText/...`);
  - `out/verify.txt` — версия игры и покрытие кириллицы шрифтами в готовом файле.

## Версия игры

`01-extract` считает SHA-256 чистого `resources.assets` и ищет его в `data/versions.json`.
Если версия найдена — печатается номер (и сведения из реестра), результат сохраняется
в `work/version.json`. Если хеш неизвестен — выводится предупреждение, сам хеш, размер файла
и подсказка из `Game version.txt`; хеш нужно добавить в `data/versions.json`.

`work/version.json` содержит: `version` (номер или `null`), `known` (`true`, если хеш найден),
`sha256`, `size` и `entry` (запись реестра). Этот файл читают `02-apply` и `03-generate`
(печатают версию, `03-generate` пишет её в `out/verify.txt`), поэтому к нему удобно привязывать
особые правила для отдельных версий, например `if version["version"] == "1.3.7": ...`.

Формат записи в `data/versions.json`:

- `version` — версия игры (`1.3.7`);
- `menu`, `unity`, `note` — справочные сведения;
- `sha256`, `md5`, `size` — идентификаторы чистого `resources.assets` (до установки перевода).

## Форматы данных

`data/settings.json`:

- `game_dir` — путь к папке игры по умолчанию (можно оставить пустым и передавать `--game`);
- `assets` — путь к `resources.assets` внутри папки игры;
- `work_dir`, `out_dir` — рабочие папки;
- `target_column` — имя колонки с целевым языком (`English`);
- `blacklist` — служебные таблицы, которые не переводятся;
- `fonts` — какие `Font`-ассеты каким TTF заменяются;
- `tmp` — параметры TMP-шрифта (`asset`, `source_font`, `atlas_texture`, `atlas_size`, `old_atlas_size`);
- `menu_text` — откуда брать `menuText_*.json` и из какой таблицы подписи.

`data/translations/<таблица>.tsv` (TSV без заголовка, строки с `#` игнорируются):

- `ключ<TAB>перевод` — перевод в колонку(и) целевого языка;
- `ключ<TAB>номер колонки<TAB>перевод` — точечно в конкретную колонку (нужно для таблиц
  с несколькими текстовыми колонками, например `delusionItemText_English`
  и `bookData_AllLanguages`).

`data/dictionary.tsv` — `английский текст<TAB>перевод`; применяется к любой ячейке,
чей текст совпадает с ключом. Удобно для строк, которые в новой версии переехали в другую таблицу.

## Шрифты

В комплекте лежат готовые TTF с кириллицей:

- `alagard_cyr.ttf` — Alagard (диалоги, книги, подсказки);
- `romulus_cyr.ttf` — пиксельный UI-шрифт Romulus (кириллица дорисована на его родной сетке);
- `dos_cyr.ttf` — моноширинный PerfectDOSVGA437 (кириллица вписана в клетку 9 px).

Если в новой версии игры появится ещё один шрифт без кириллицы, его TTF кладут в `data/fonts`
и добавляют строку в `settings.json → fonts`. Покрытие кириллицы проверяют `02-apply` и
`03-generate`.

## Правила и подводные камни

- Сборка всегда берёт **чистый** файл игры: если перевод уже установлен, оригинал должен лежать
  в `resources.assets.orig` или `resources.assets.bak`.
- Колонки для перевода выбираются по слову `English` в заголовке; если таких нет
  (таблицы предметов), используются все колонки кроме первой — это безопасно, потому что
  в TSV пишутся только те колонки, где в готовом переводе действительно был русский текст.
- `work/` и `out/` — рабочие каталоги, их можно удалять и собирать заново.
- Обнулять таблицы глифов/символов TMP нельзя: после этого TextMeshPro сопоставляет символы
  с неверными глифами и текст превращается в мусор. Рабочий способ — расширение атласа и
  свободная полоса под старым содержимым (так делает `03-generate`).
